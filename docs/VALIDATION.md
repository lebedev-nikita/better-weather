## Работа с реальными данными

Живой запрос к Open-Meteo для Тбилиси вернул 168 часов, семь дней и `Asia/Tbilisi`. UV доступен по часам; ветер запрошен в м/с.

В Android-эмуляторе API 36 проверены:

- Загрузка реальной текущей погоды, почасового и недельного прогноза.
- Поиск `Batumi`, выбор Батуми и сохранение города после перезапуска процесса.
- Разрешение геолокации: отказ оставляет доступным поиск города; приблизительное разрешение позволяет получить прогноз для координат эмулятора. GPS-позиция эмулятора задана около Тбилиси; тестирование реального GPS на устройстве не проводилось.
- Добавление виджета через системный диалог лаунчера, отображение температуры/ветра/UV, ручное обновление виджета.
- Системная задача WorkManager запланирована с ограничением сети и интервалом примерно час. Ожидание полного часового интервала и измерение энергопотребления на физическом устройстве не проводились.
- Отключение Wi-Fi и мобильных данных: после попытки обновления прогноз остаётся на экране, появляется «Без сети» и время сохранения. Восстановление сети и повторное обновление возвращают обычное состояние.
- Светлая и тёмная темы, масштаб системного шрифта 1,3.
- Телефон 1080×2400 / 420 dpi; широкий экран 1600×2560 / 240 dpi смоделирован сменой параметров того же эмулятора. На широком экране используется две колонки.

Снимки реального Android-интерфейса находятся локально в `.impeccable/review/` (не включаются в Git). Условия и время на снимках отличаются: это живые данные в процессе проверки.

Независимая проверка интерфейса по исходному коду и восьми снимкам Android-эмулятора завершилась вердиктом `ship`: существенных исправлений не потребовалось. Проверены исполнение требований, читабельность, состояния, нативные элементы управления и адаптация ширины.
