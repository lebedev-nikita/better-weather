# Better Weather

Нативное приложение погоды для **Android 8.0+**, написанное на **Kotlin и Jetpack Compose**. Русский интерфейс, светлая и тёмная темы, °C и м/с. API-ключ и регистрация не нужны.

Релиз-кандидат: [v0.1.1-rc.6](https://github.com/lebedev-nikita/better-weather/releases/tag/v0.1.1-rc.6). Для установки скачайте `BetterWeather-0.1.1-rc.6.apk` из приложенных файлов; SHA-256 находится рядом. Стабильный выпуск: [v0.1.0](https://github.com/lebedev-nikita/better-weather/releases/tag/v0.1.0).

## Возможности

- Текущая температура, ощущаемая температура, ветер и направление, UV-индекс, влажность.
- Почасовой прогноз на весь текущий день. Выбор часа показывает ветер, вероятность осадков и UV.
- Семь дней прогноза: минимум/максимум температуры, погодные условия и вероятность осадков.
- Поиск городов с уточнением региона и страны; выбранное место сохраняется.
- Геолокация по кнопке «Моё местоположение», включая приблизительное местоположение. Разрешение запрашивается только после нажатия. При отказе доступен поиск города.
- Компактный виджет главного экрана: иллюстрация погоды слева, температура в центре, ветер и UV справа, время обновления справа от города. Нажатие открывает приложение; каждое открытие приложения запрашивает свежий прогноз и обновляет виджет.
- Фоновое обновление виджета через WorkManager с интервалом 15 минут. Это минимальный период WorkManager; точное время запуска зависит от Android, сети и энергосбережения. При обновлении приложения прежнее часовое расписание заменяется автоматически. Фоновой геолокации нет: виджет обновляет последнее выбранное место.
- Последний прогноз хранится локально. При сетевой ошибке данные остаются на экране; время сохранения и устаревший прогноз обозначаются явно.
- Белый фон приложения и виджета в светлой теме; тёмная тема включается вместе с системной.
- Готовые цветные погодные иллюстрации в текущей погоде, почасовом и недельном прогнозах и виджете; изображения доступны без сети.
- На широких экранах текущие условия и прогноз располагаются в двух колонках.

При первом запуске предлагается Тбилиси. Это изменяемый начальный город, а не автоматически определённое местоположение.

## Сборка и установка

Откройте репозиторий в Android Studio и дождитесь Gradle Sync. Нужны **JDK 17+**, **Android SDK Platform 36** и SDK Build Tools. Gradle Wrapper входит в репозиторий; Android Studio создаёт `local.properties` с путём к SDK.

Для сборки из терминала задайте `ANDROID_HOME` или создайте `local.properties`:

```properties
sdk.dir=/absolute/path/to/Android/sdk
```

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Запустите Better Weather и выберите город. Чтобы добавить виджет, удерживайте свободное место на главном экране → Виджеты → Better Weather.

`./gradlew :app:assembleRelease` собирает оптимизированный APK. Без настройки подписи результат будет неподписанным.

Для подписанной сборки сохраните настройки в приватном файле вне репозитория:

```properties
storeFile=/absolute/path/to/release.p12
storePassword=your-private-password
keyAlias=better-weather
keyPassword=your-private-password
```

```sh
BETTER_WEATHER_SIGNING_PROPERTIES=/absolute/path/to/signing.properties ./gradlew :app:assembleRelease
```

Подписанный результат: `app/build/outputs/apk/release/app-release.apk`. Ключ первого релиза и его настройки сохранены на машине выпуска в `~/.config/better-weather/signing/`; они не включаются в Git или релиз. Сохраните приватную резервную копию этих файлов и используйте тот же ключ для обновлений. Правила подписи описаны в [документации Android](https://developer.android.com/studio/publish/app-signing).

Release APK использует отдельную подпись. Если ранее установлена отладочная сборка из этой сессии, перед установкой релизной сборки её нужно удалить; сохранённый город при этом удалится.

## Бесплатные API и данные

[Open-Meteo Forecast API](https://open-meteo.com/en/docs) предоставляет текущие, почасовые и дневные данные. [Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api) ищет города; геокодинг использует GeoNames. Приложение обращается к API напрямую по HTTPS.

Время определяется по **часовому поясу выбранного места**, включая выбор текущего дня и часа. UV берётся из **почасового `uv_index`**; дневной максимум не выдаётся за текущий UV. Отсутствующие значения отображаются как «—», а не ноль. Погодные условия интерпретируются по кодам WMO.

Бесплатный endpoint Open-Meteo предназначен для **некоммерческого использования** и имеет ограничения запросов. Для коммерческого распространения нужно выбрать соответствующий тариф или развернуть собственный сервер: [условия и тарифы](https://open-meteo.com/en/pricing). Данные лицензированы по **CC BY 4.0**; ссылка на Open-Meteo есть в приложении. Данные округляются для отображения, ветер запрашивается в м/с.

Координаты выбранного места передаются в Open-Meteo для загрузки прогноза, текст поиска — в Geocoding API. Последнее место и прогноз сохраняются в SharedPreferences; резервное копирование этих данных отключено. Аналитики, аккаунтов и собственного сервера нет.

Погодные иллюстрации — готовый набор [Weather Icons](https://github.com/Makin-Things/weather-icons) от Makin-Things на основе amCharts. Исходники, лицензии и преобразование для Android описаны в [third_party/weather-icons](third_party/weather-icons/README.md). Изображения входят в APK и доступны без сети.

## Структура

```text
app/src/main/java/dev/betterweather/
  data/       модели, HTTPS-клиент, парсинг и атомарный кэш
  location/   однократное определение местоположения
  ui/         экран Compose, тема и ViewModel
  widget/     RemoteViews-виджет и WorkManager
```

Пять небольших unit-тестов проверяют часовой пояс, выбор текущего UV, границы недельного прогноза, отсутствующие значения и коды погоды:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug
```

Нативные instrumented-тесты проверяют отсутствие обрезания значений виджета при размере 240/360 × 140dp и шрифте 100%/130%, а также переход с часового на 15-минутное расписание без дубликатов. Для них нужен эмулятор или устройство с отладочной сборкой:

```sh
./gradlew :app:connectedDebugAndroidTest
```
